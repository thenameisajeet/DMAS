Project Title - Disaster Alert Broadcast Dashboard (DMAS)

Solution - The Disaster Alert Broadcast Dashboard (DMAS) is a real-time emergency communication system designed to rapidly broadcast disaster alerts and safety instructions to students and staff.

The system provides a secure admin dashboard where authorized personnel can trigger emergency alerts such as fire alerts, flood warnings, earthquake emergencies, and evacuation notices. Once an alert is issued, all connected users instantly receive the alert through the student safety portal along with push notifications.

Features of the system include:

• Secure Admin Authentication
• Student Registration & Login System
• Real-Time Alert Broadcasting
• Emergency Status Monitoring
• Push Notification Support
• Firebase Cloud Integration
• Responsive Student Dashboard
• Live Incident Updates & Alert History

The platform is designed to ensure fast, reliable, and centralized emergency communication during critical situations, helping users take immediate action and remain safe.
